A tiny chess engine in 4,096 bytes of Python for make.fun tiny-chess-01: a 0x88 board, alpha-beta search with a transposition table, killer moves and MVV-LVA ordering, quiescence over captures and promotions, a check extension, and a fixed 50,000-node budget per move. It plays the house gauntlet through the trial env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
